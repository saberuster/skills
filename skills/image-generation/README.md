# Image generation

Skills for preparing GPT Image prompts from briefs, reference images, and
established requirements. These skills produce prompt text only.

## Skills

- [Brief to Image Prompt](brief-to-image-prompt/README.md): develop an idea or
  brief into a prompt, resolving important creative preferences first.
- [GPT Image Prompting](gpt-image-prompting/README.md): structure or revise a
  prompt using the shared prompt standard.
- [Image to Prompt](image-to-prompt/README.md): describe a reference image or
  extract its requested style, composition, or features as a prompt.

## Installation

Install each skill from its own subfolder using the
[shared installation protocol](../../docs/installation.md). Both entry skills
require `gpt-image-prompting` in the host's available skills. Install packages
under their existing skill names; this collection is not an installable skill.
