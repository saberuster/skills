# Thinking

Skills for exploring ideas, clarifying questions, and working through decisions.

## Skills

- [Talk It Through](talk-it-through/README.md): develop ideas, compare
  alternatives, and clarify trade-offs through focused discussion while the user
  keeps consequential choices.

## Installation

Install the selected skill from its own subfolder using the
[shared installation protocol](../../docs/installation.md). Retain its leaf name
as the skill identifier; this collection is not an installable skill.
